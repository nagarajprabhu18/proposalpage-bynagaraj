# A Little Something for You

A mobile-first, seven-scene proposal experience built with React, Vite, Framer Motion, Lucide, and CSS. Progress is saved in `localStorage` under `little-love-story`.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Story artwork is intentionally made from CSS gradients and small illustrations, so it can be replaced without changing the story flow. Update the `story` array in `src/App.jsx` to customize the four captions and descriptions.
